Sunset Bay — an original open-world crime game in a sun-soaked coastal city. Explore on foot or behind the wheel, steal cars, outrun the Sunset Bay PD under a five-star wanted system, and run three story missions for Lena Marlowe: steal a car, collect her packages, and lose the heat. Traffic, pedestrians, police chases, combat, a HUD with a live minimap, and an autosave — all running offline in a desktop browser from static files, with three.js vendored and every sound synthesized live with WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```

Controls: WASD or arrow keys to move and drive, mouse drag to orbit the camera, Shift to run, E to steal or exit a car, click to shoot, Space to brake or jump, P to pause, M to mute.
